⚡ Quickstart
Clone the repo:

bash
git clone https://github.com/NChoudhary614/simple-python-unit-testing-demo.git
cd simple-python-unit-testing-demo
(Optional) Set up a virtual environment:

bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
Run your code:

bash
python src/main.py
Run the automated tests:

bash
python -m unittest discover -s tests
